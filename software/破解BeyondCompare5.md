# 2. 官网下载`010 Editor`

# 3. 编辑`.exe`

## 3.1 方法来源

先看这个[Github Repo](https://github.com/garfield-ts/BCompare_Keygen)。


## 3.2 以管理员权限打开`010 Editor`

## 3.3 在`010 Editor`中打开`BCompare.exe`

具体的`BCompare.exe`的路径，在桌面右键，属性里可以找到它的安装路径。

## 3.4 更改`.exe`中的二进制RSA密钥

按下`ctrl` `f`，并选择更改搜索方式为`Text`

![image](../png/software/15.png)

搜索内容输入`p1+wk`，将其修改为`pn+wk`。

保存，完成RSA密钥的破解。

# 4. 顺着Github Repo中的生成方式，生成虚假密钥，激活Beyond Compare5

即可完成。
