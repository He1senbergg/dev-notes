# 修改默认打开新文件夹在新窗口

- 打开设置`Ctrl` + `,`
- 搜索：
   ```
   window open folders in new window
   ```
- 找到这个选项：

👉 **Window: Open Folders In New Window**

- 把它改成：

```text
on
```

![image](../../png/software/36.png)

三个选项含义

| 值            | 行为               |
| --------------- | -------------------- |
| `on`      | 总是新窗口打开     |
| `off`     | 总是在当前窗口打开 |
| `default` | 👉 每次弹窗询问    |
