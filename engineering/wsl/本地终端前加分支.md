打开配置文件。

```
vim /home/heisenberg/.bashrc
```

按下大写G，到了文件最后，追加写入下面的内容。

```
# git branch prefix

if [ -f /usr/lib/git-core/git-sh-prompt ]; then
source /usr/lib/git-core/git-sh-prompt
fi

PS1='$(__git_ps1 "(%s) ")'"$PS1"
```

写入完成，保存退出，激活配置。

```
:wq
source /home/heisenberg/.bashrc
```
