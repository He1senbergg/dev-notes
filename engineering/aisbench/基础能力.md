# 1. 性能验证材料准备

- aisbench conda环境: CondaEnv.tar.gz
- benchmark运行代码: benchmark.zip
- miniconda软件包: Miniconda3-py311_24.7.1-0-Linux-aarch64.sh

ps：CondaEnv.tar.gz以及benchmark.zip如果无法上传到环境上，报错拦截的话，可以先重命名将后缀去掉上传后再在环境上将其重命名回去解压
将以上三个传到环境上，放在某个路径下，推荐放在llm服务容器内外挂载路径下：
容器外：/opt/container/log/10/llmservice ----> 容器内：/opt/coremind/logs

# 2. 测试环境准备以及参数修改

在容器内cd到存放步骤1中文件的路径

```
cd {target path}
```

## 2.1 安装Miniconda

```
bash Miniconda3-py311_24.7.1-0-Linux-aarch64.sh
```

按照安装指示执行即可，yes or no全填yes

![image](../../png/engineering/48.png)

到上图即为安装成功。

## 2.2 安装aisbench运行环境

解压CondaEnv.tar.gz

```
tar -zxvf CondaEnv.tar.gz
```

将解压出来的conda环境包移动到指定miniconda环境路径下

```
mv CondaEnv /root/miniconda3/envs/
```

执行完成后，退出重新进入容器

![image](../../png/engineering/49.png)

容器前会出现base，即miniconda安装完成
启用aisbench环境

```
conda activate aisbench
```

此时容器前base变为aisbench，aisbench运行环境安装成功

![image](../../png/engineering/50.png)

## 2.3 安装aisbench

在容器内放置benchmark路径下{target path}路径下

```
unzip benchmark.zip
cd benchmark
```

到benchmark路径下

（1）修改证书路径

```
vi ais_bench/benchmark/models/api_models/base_api.py
```

![image](../../png/engineering/51.png)

（2）修改推理参数

```
vi ais_bench/benchmark/configs/models/fusionmind_api/fusionmind_api_stream_chat_multiturn.py
```

![image](../../png/engineering/52.png)

此文件修改以上六个参数，参数具体意义：
- ①：aisbench使用的模型路径，实际上我们需要的只是一个tokenizer文件，可以直接使用推理容器内本身的tokenizer文件，注意需要根据模型更换不同对应文件，只需要模型中的tokenizer.json、tokenizer_config.json、vocab.json，不需要模型权重，该路径即为tokenizer文件路径
    ![image](../../png/engineering/53.png)
- ②：模型名称：随便填写不做校验，但是需要填写。vLLM是需要填的。
    ![image](../../png/engineering/54.png)
- ③：推理url：可以在容器内查找
netstat -tluWn|grep 27092
- ④：最大输出长度：限制推理最大输出长度
注意：限制的只是最大输出长度，但是会出现推理结果远小于最大输出长度的情况，如果要严格控制输出达到1200在promt里面写例如：请帮我输出不少于xxx字
- ⑤：bacthsize根据自己的场景进行修改即可
- ⑥：是否进行后处理，对于mindieservice将generation_kwargs里的参数都删掉置为空则为不开启后处理，但是对于llmservice，置为空之后会走llmservice的默认参数，此时temperature会被置为0.9影响投机推理性能，ToB场景需要将temperature置为0.2进行性能测试

（3）修改数据集路径

```
vi ais_bench/benchmark/configs/datasets/mtbench/mtbench_gen.py
```

![image](../../png/engineering/55.png)

# 3. 运行aisbench

导入环境变量-----benchmark路径

```
export PYTHONPATH=/opt/coremind/logs/benchmark/
```

运行aisbench

```
ais_bench --models fusionmind_api_stream_chat_multiturn --datasets mtbench_gen -m perf
```
