# 一、命令行指令

## 1. 所有用户获得所有权限

每个数字代表一组权限：​**文件所有者**​、**文件所在的组** 和 ​**其他用户**​。每个数字可以是 0 到 7 之间的一个值，具体含义如下：

* **读（r）** 权限：值为 `4`
* **写（w）** 权限：值为 `2`
* **执行（x）** 权限：值为 `1`

这些权限可以加起来形成不同的值。例如：

* `7` = `4 (读) + 2 (写) + 1 (执行)`，表示读、写、执行权限都被赋予了。

**举例解释 `777`**

`777` 的每个数字都对应文件或目录的三组权限：

* ​**第一个 7**​：文件所有者的权限 (Owner)
* ​**第二个 7**​：文件所属组的权限 (Group)
* ​**第三个 7**​：其他用户的权限 (Others)

每个 `7` 代表文件或目录的读、写、执行权限都被赋予，因此 `777` 表示：

* ​**所有者**​：可以读、写、执行该文件或目录。
* ​**所属组**​：可以读、写、执行该文件或目录。
* ​**其他用户**​：可以读、写、执行该文件或目录。
  

### 1.1 当前目录下设置所有权限

```
sudo chmod 777 *
```

### 1.2 选择某目录下设置所有权限

```
sudo chmod 777 "/path/to/directory"
```

### 1.3 递归为当前目录的所有子文件(夹)设置所有权限

```
sudo chmod -R 777 *
```

### 1.4 递归为某目录的所有子文件(夹)设置所有权限

```
sudo chmod -R chmod 777 "/path/to/directory"
```

## 3. 执行bash文件

### 3.1 默认执行bash文件

```
bash example.sh
```

### 3.2 详细展示bash文件的执行过程

```
bash -x example.sh
```

**调试脚本执行**：使用 bash -x 执行脚本时，Bash 会在每个命令执行之前打印该命令和命令中的变量、参数等信息。

**查看命令展开过程**：它可以帮助你查看命令的展开过程（例如，变量的替换、命令替换等），有助于调试复杂的脚本。

**示例**

假设有一个简单的脚本 `example.sh`，内容如下：

```
#!/bin/bash
a=5
b=10
echo "The sum of a and b is: $((a + b))"
```

如果直接运行该脚本：

```
./example.sh
```

输出为：

```
The sum of a and b is: 15
```

但是，如果你用 `bash -x` 来执行脚本，像这样：

```
bash -x example.sh
```

你将看到以下的输出：

```
+ a=5
+ b=10
+ echo 'The sum of a and b is: 15'
The sum of a and b is: 15
```

**输出解释**

* 每一行前面的 `+` 符号表示该命令正在执行，并且会显示命令以及其展开后的内容（包括变量的值）。
* `+` 后面的命令是实际执行的命令，这样你就可以清楚地看到变量的值以及命令是如何展开的。

## 4. 查询当前系统中进程的IP

```
netstat -tluWn
```

`-t`：显示 TCP 连接（t = TCP）
`-l` ：只显示**监听（Listening）状态**的端口（不是所有连接）
`-u` ：显示 UDP 连接（u = UDP）
`-W`：防止输出被截断（W = wide，显示完整地址/端口名，避免省略号）
`-n`：以**数字**显示地址和端口，而不是尝试解析成域名和服务名（更快）

# 二、Docker指令

## 1. 获取节点信息

```
kubectl get pod -n 命名空间 -owide | grep 关键词 | tr - :
```

* `kubectl get pod -n 命名空间`：**必写项**
* `-owide`：可选项，展示详细IP
* `|`：可选项，将其它命令与`grep 关键词`、`tr - :`等**过滤命令**进行分割开
* `grep 关键词`：可选项，过滤命令，搜索关键词
* `tr - :`：可选项，过滤命令，将搜索结果中可能出现的`-`替换为`:`
* 空格可以不止一个，没有明确规定
* 过滤命令需要写在`|`之后，其余代码需在`|`之前输入

## 3. 进入容器内部

```
docker exec -it --privileged -u 用户ID 容器进程ID bash
```

* `docker exec`：**必写项**
* `-it`：可选项，将容器在前台显示
* `--privileged`：默认情况下，Docker 容器是“受限的”，不能访问主机的一些底层资源。使用 `--privileged` 相当于让容器获得root
* `-u 用户ID`：用于指定容器内运行的用户，`-u 0` 的意思就是以 UID 为 0 的用户运行容器
* `容器进程ID`：**必写项**，在**2. 查询当前所有的容器**中的运行结果的每一行的第一个即为容器进程ID
* 空格可以不止一个，没有明确规定
