## 1.  在paas后台，使用

```
kubectl get pod -n <命名空间> -owide | grep <节点名称的部分>
```

示例代码

```
kubectl get pod -n yzv433 -owide | grep llm
```

![](../../png/engineering/87.png)

## 2. 得到节点的名称，使用

```
kubectl exec -it -n <命名空间> <节点名称> bash
```

示例代码

```
kubectl exec -it -n yzv433  llmservice-6b695c7f55-2kqrq bash
```

得到节点内的容器显示，示例如下：

（注：此时已经在节点内的默认的第一个容器的内部。）

![](../../png/engineering/88.png)

在如图中的结果里，找到目标容器的名称。
