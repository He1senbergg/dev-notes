# 3. Windows上打开PowerShell

## 3.1 检查前面设置的`9999`端口

```
netstat -aon|findstr "9999"
```

出现一大堆就是正常。只有两个就重启一下Windows。

![image](../../png/engineering/18.png)

## 3.2 获取IP

输入

```
ipconfig /all
```

![image](../../png/engineering/19.png)

![image](../../png/engineering/20.png)

# 4. 远端服务器操作

输入

```
export http_proxy=http://实际IP:9999
export https_proxy=http://实际IP:9999
wget www.baidu.com
```

示例

```
export http_proxy=http://141.5.148.26:9999
export https_proxy=http://141.5.148.26:9999
wget www.baidu.com
```
